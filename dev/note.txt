2) Fonctionnement semaine A / semaine B

- Intégrer discrètement le mode semaine A / semaine B

- Sur l’emploi du temps global : afficher deux box dans un créneau
	(pour visualiser discrètement l’alternance A/B)

4) Contraintes de ressources / professeurs

- Regrouper plusieurs professeurs sur un même créneau
- Ce créneau peut ne concerner aucune classe mais doit être placé
	- Exemple : Isabelle, Margentine, Maguelonne, Pierre, Sophie,
		Chanoine dainville (réunion sans classe)

- Impression actuelle : le système semble agir comme s’il y avait trop de
	professeurs pour une matière, avec choix possible entre eux


5) Stratégie de génération

- Autoriser deux types de contraintes :
	1. Classes regroupées sans horaires précis
	2. Horaires précis

- Lancer la génération avec ce qui est le plus restrictif :
	- en nombre d’heures
	- en nombre de disponibilités sur les créneaux

- Commencer par les disponibilités les plus restrictives
- Identifier les professeurs « goulots d’étranglement »
- Pouvoir savoir globalement s’il existe une solution d’emploi du temps
